# Premium UI Designer Skill

Use this skill when redesigning landing pages, dashboards, marketing websites, SaaS pages, and app interfaces.

## Design rules
- Make the UI clean, premium, modern, and production-ready.
- Avoid generic template design.
- Use strong spacing, readable hierarchy, and balanced composition.
- Keep animations smooth and useful, not distracting.
- Prioritize mobile responsiveness.
- Use accessible contrast.
- Keep sections visually connected.
- Avoid overcrowding the screen.

## For Xilolo
- Main light color: #e5e4e2
- Main dark color: #050505
- Accent red should be used only for live status, highlights, and important emphasis.
- Visual feel: premium, cinematic, realistic, 3D, live-streaming, creator economy.
- Use glass cards, floating metric cards, subtle shadows, soft gradients, and scroll-based motion.
- Do not make the interface childish or too colorful.

## Implementation behavior
- Inspect the existing project before editing.
- Reuse existing components when possible.
- Create reusable components when needed.
- Keep routing and backend logic untouched.
- Make the UI responsive across desktop, tablet, and mobile.
- Add reduced-motion support.
- Run lint/build checks after changes.
